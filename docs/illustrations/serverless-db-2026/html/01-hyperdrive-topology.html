Hyperdrive 用 5432 不要用 6543 套 pooler
本地开发例外（故意不同） 本机够不到 CF 内网 Hyperdrive。常用 Supavisor Transaction Mode： …:6543。两套连接串是架构结果，不是临时补丁。
坑：prepared statements

本地 6543 transaction mode 对 prepared statement 支持受限 →「本地玄学报错、线上正常」。本地关 prepare。

Hyperdrive 缓存边界

只缓存可缓存读。写、事务、含易变函数的查询直达数据库，一致性不用靠猜。

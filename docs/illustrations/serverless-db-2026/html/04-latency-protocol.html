D1 binding

同平台 · 原生绑定

稳态通常最省心
Sessions注意瞬时断连
  • 适合读多写少应用库
  • Network connection lost 用白名单重试
  • 不要把错误字面当「过载」结论
CF 全家桶默认首选测点

Hyperdrive

池化 · 源库地理仍在

握手税可被池消掉
下限受源库位置约束
  • 对比「直连 vs Hyperdrive」才有意义
  • Query Cache 只帮可缓存读
  • 本地 6543 与线上 5432 勿混测
测的是接入层 + 源库，不是边缘库

MuiRouter · 计费

定价是矩阵，不是两个单价

单位：美元 / 1M tokens
再乘 markup 与用户倍率
token 类别 标准档 standard 长上下文档 long_context
普通输入 inputPrice longContextInputPrice
cache 命中输入 cachedInputPrice longContextCachedInputPrice
cache 写入 cacheWritePrice longContextCacheWritePrice
输出 outputPrice longContextOutputPrice
档位怎么判

contextSize = input + cachedInput + cacheWrite。超过 longContextThresholdTokens 走长上下文档，否则标准档。

缺省字段回退同名标准价 cache 价缺省 → inputPrice
rawCost = Σ(token × 单价) / 1e6
cost = rawCost × markupRate × userRateMultiplier
chargedCost = max(0, cost − freeQuota)
钱包只扣 chargedCost · D1 记全量 cost + 四类 token
特殊计量仍进同一管道
  • Grok 图片 ticks → 内部 token 再走 markup
  • 视频：预占 reservation → 终态按实际结算
  • 幂等：reservation id + usage_logs.id + billed_at

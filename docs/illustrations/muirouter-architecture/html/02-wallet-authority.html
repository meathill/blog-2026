MuiRouter · 账本正确性

KV 镜像 vs WalletDO 权威 vs D1 审计

「唯一写者」必须用结构保证
注释挡不住旁路覆盖

WalletDO = 余额唯一写者

按 idFromName(userId) 分区。读 storage → 变更 → 写 storage 整段包进 blockConcurrencyWhile（段内无外部 I/O）；KV 镜像同步放锁外。

权威账本 · Durable Object storage

余额 / 免费额度已用 / 暂停状态 / 视频预占 reservation。所有扣费与充值只进这里。

唯一写入口 同用户串行

KV · 只读镜像

user:{id} 给热路径展示与鉴权辅助。任何「只改一个字段」的读改写 = 整条覆盖。

D1 · 流水审计

usage_logs / recharge / 定价 / OAuth。可查、可聚合，不是钱包真相。

ConcurrencyLimiterDO

只管 lease。并发数字段也走 WalletDO /set-concurrency，禁止碰余额键。

app Worker 与 dashboard Worker 都通过 DO 绑定写钱包 · 本地双 dev 进程无跨 Worker 绑定属工具链限制
